# Expense Tracker

A personal expense-tracking application built with Python and Flet.

## Features

- Track income and expenses
- Categorize transactions
- Calculate available balance
- Store transactions locally using SQLite
- View transaction history
- Delete transactions

## Technologies

- Python
- Flet
- SQLite
- Git and GitHub

## Installation

1. Install Python.
2. Open a terminal in the project folder.
3. Create a virtual environment:

   python -m venv .venv

4. Activate it on Windows:

   .\.venv\Scripts\Activate.ps1

5. Install Flet:

   python -m pip install flet

6. Run the app:

   python app.py

## Privacy

Transactions are stored locally in expenses.db.
The database is excluded from version control.
